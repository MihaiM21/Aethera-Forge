# Aethera — conventions for workers

Aethera is a self-hosted deployment platform (Coolify alternative). Read `docs/plan.md` (approved plan), `docs/roadmap.md` (status) and relevant `docs/architecture/*.md` ADRs before starting. Product spec: `docs/idea/01_AppIdea.md`.

## Layout
```
src/control-plane/   .NET 10 solution Aethera.slnx: src/{Aethera.Api,Domain,Infrastructure,Engine}, tests/{Aethera.Api.Tests,Aethera.Domain.Tests}
src/agent/           Go module github.com/mihaim21/aethera-forge/agent (cmd/aethera-agent, internal/*, gen/ = generated proto code)
src/web/             Next.js (App Router, static export, Tailwind v4, shadcn/ui), pnpm
proto/               Agent protocol (buf). buf.yaml / buf.gen.yaml at repo root
deploy/              docker-compose.dev.yml (Postgres 17, Redis 7)
scripts/             session-start.sh (Claude Code cloud bootstrap)
```
Dependency direction (.NET): Api -> Infrastructure, Engine -> Domain. Domain depends on nothing. NuGet versions live only in `Directory.Packages.props`; shared settings (net10.0, nullable, warnings as errors) in `Directory.Build.props`.

## Build and test
.NET (SDK 10 lives in `$HOME/.dotnet`):
```bash
export DOTNET_ROOT=$HOME/.dotnet PATH=$HOME/.dotnet:$HOME/go/bin:$PATH DOTNET_CLI_TELEMETRY_OPTOUT=1
cd src/control-plane && dotnet build -warnaserror && dotnet test
```
Agent:
```bash
cd src/agent && go vet ./... && go test ./... && make cross   # static linux/amd64 + arm64 in dist/
```
Web:
```bash
cd src/web && pnpm install && pnpm lint && pnpm build        # build emits static site to out/
```
Proto (only when told to change it): `export PATH=$HOME/go/bin:$PATH; buf lint && buf generate`. Go code is generated into `src/agent/gen`; C# is generated by Grpc.Tools at build time, not committed.

Cloud sessions run `scripts/session-start.sh` automatically (installs .NET 10, buf, protoc plugins, restores deps). Egress is policy-restricted: some hosts (e.g. builds.dotnet.microsoft.com, ui.shadcn.com) are blocked; NuGet, npm, Go proxy and the Ubuntu archive work.

## Rules
- **Contracts**: `proto/`, DB migrations and OpenAPI conventions are owned by the orchestrator. Do not change them without being told to.
- Stay inside the paths your work package owns; parallel workers must not overlap.
- **Commits**: Conventional Commits (`feat(api): ...`, `fix(agent): ...`, `chore:`, `docs:`, `test:`). Small logical commits. Do not push unless instructed.
- **No secrets in logs**, errors or test output. Secrets are encrypted at rest, masked in the UI, redacted from logs.
- **Tests are required** for new code (xUnit, `go test`); keep builds warning-free.
- The agent executes only typed, allowlisted commands; never add arbitrary shell execution.
- API first: the UI must not contain logic the API lacks.
- **UI** must follow the "Design system" section of `docs/plan.md` (dark default, lime accent `#b8f26b`, mono labels, square corners, 1px borders, dotted-grid canvas).
